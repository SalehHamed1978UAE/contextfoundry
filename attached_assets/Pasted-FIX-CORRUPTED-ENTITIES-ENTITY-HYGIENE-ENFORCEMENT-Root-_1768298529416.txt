FIX CORRUPTED ENTITIES — ENTITY HYGIENE ENFORCEMENT

Root cause: Entities with embedded newlines slipping through:
- "Elizabeth Morrison\n\nThomas Bradley" 
- "Amanda Foster\n\nSusan Martinez"
- "PARTNER COMPENSATION\n\nElizabeth Morrison"

When querying "Who is the CFO?", the corrupted entity returns "Elizabeth Morrison" 
instead of "Thomas Bradley".

STEP 1: FIX ENTITY HYGIENE — CHECK NEWLINES BEFORE NORMALIZATION
================================================================================

In entity_hygiene.py (or wherever validation happens):
```python
def is_valid_entity_name(name: str) -> bool:
    """Validate entity name BEFORE any normalization"""
    
    if not name:
        return False
    
    # CRITICAL: Check for newlines BEFORE whitespace normalization
    if '\n' in name or '\r' in name:
        logger.warning(f"Rejecting entity with embedded newline: {repr(name)}")
        return False
    
    # Check for multiple names concatenated (common corruption pattern)
    # Pattern: "Name1\n\nName2" after normalization becomes "Name1  Name2"
    if '  ' in name:  # Double space indicates concatenation
        logger.warning(f"Rejecting entity with double space: {repr(name)}")
        return False
    
    # Existing validations
    if len(name.strip()) < 2:
        return False
    
    if name.upper() in INVALID_ENTITY_NAMES:
        return False
    
    return True
```
