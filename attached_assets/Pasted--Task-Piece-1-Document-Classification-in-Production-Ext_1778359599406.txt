## Goal

Wire document classification metadata into the production extraction path.

Every document gets a structured classification result before extraction runs. Metadata is persisted on the canonical documents table and passed to `MultiModelExtractor`.

**Extraction prompt behavior must not change in this Piece.** Prompt generation is Piece 2.

## Locked Decisions

Do not re-audit these unless files contradict `docs/architecture.md` or `docs/decisions.md`.

1. Two classifiers, two roles:
   - `brain/classifier.py` is the canonical **domain** classifier.
   - `src/context_foundry/extraction/document_classifier.py` is the canonical **document_type** classifier.
   - They serve different axes and must not be confused.

2. The classifier wrapper uses both:
   - domain from `brain/classifier.py`
   - document_type from `extraction/document_classifier.py`

3. `secondary_domains` exists but returns `[]` this iteration.

4. Piece 1 is metadata flow only:
   - no prompt content changes
   - no Gardener changes
   - no domain-aware extraction yet

5. `classification_status` default is intentionally `unclassified`.
   Pre-existing documents that predate this Piece must default to `classification_status='unclassified'`, not `'ok'`. The system distinguishes:
   - successfully classified: `ok`
   - classification attempted and failed: `failed`
   - never classified: `unclassified`

   Defaulting unclassified rows to `ok` would silently assert successful classification where none occurred. That is the kind of semantic drift the architecture is designed to prevent.

## A. Build classifier wrapper

Create a wrapper, either in `brain/classifier.py` or a new `brain/classification_wrapper.py`, whichever is cleaner.

It must return:

```python
{
    "primary_domain": str | None,
    "secondary_domains": list[str],
    "document_type": str | None,
    "classification_confidence": float | None,
    "classifier_version": str,
    "classification_evidence": str | None,
    "classification_status": str,       # "ok" | "failed"
    "classification_error": str | None,

Wrapper behavior:

Calls brain/classifier.py for:

classification_confidence

set primary_domain = None
set document_type = None
set classification_error
extraction must continue using existing behavior

Document this failure behavior in the wrapper docstring.
