ROOT CAUSE ANALYSIS COMPLETE

  The extraction regression is NOT a mystery - it's caused by non-deterministic ordering in multiple places. Here's the complete picture:

  ---
  THE CORE PROBLEM

  The same documents produce different relationship counts because entity ordering is non-deterministic. When the LLM sees entities in a different order, it extracts different relationships.

  WHY THIS CAUSES THE SYMPTOMS YOU SAW

  Morrison & Sterling CFO disappearing:
  - Thomas Bradley gets assigned different entity codes (E1 vs E4) each run
  - The LLM prompt sees different entity orderings
  - With different orderings, the LLM may not recognize the REPORTS_TO relationship

  Titan Manufacturing dropping from 66 → 35 relationships:
  - With 20+ entities, entity code shifts compound
  - Many relationships get "lost" because the LLM sees a completely different entity list
  - The 47% drop is consistent with entity ordering chaos

  TechVentures "Who reports to CEO?" regression:
  - In run 140927, only Marcus Williams was found
  - In run 145638, all 3 were found again
  - This is pure randomness from entity ordering + temperature

  Five surgical changes are needed:

  1. relationship_inference.py:360 - Add .order_by(EntityMention.entity_id)

  3. relationship_inference.py:443 - Change temperature=0.1 to temperature=0.0
