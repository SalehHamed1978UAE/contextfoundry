# DTL Test Instructions

## Quick Start

1. **Set environment variables:**
```bash
export CF_API_KEY="your-api-key-here"
export CF_API_KEY_2="second-tenant-key-here"  # Optional, for isolation test
export DTL_BASE_URL="http://localhost:5000"   # Or your Replit URL
```

2. **Run the test:**
```bash
python test_dtl_e2e.py
```

## What It Tests

| Test | What It Verifies |
|------|------------------|
| Health Check | DTL API is running |
| Auth Required | Unauthenticated requests are blocked |
| Seed Decisions | Can create decisions with evidence |
| Exact Search | Can find decisions by similar text |
| Semantic Search | Can find decisions by meaning (not just keywords) |
| Ranking | Most relevant results appear first |
| Retrieval | Can get individual decisions by ID |
| Cross-Tenant | Other tenants can't see your decisions |
| Agent Logger | Agent-created decisions are searchable |
| Evidence Required | Can't enact decisions without evidence |

## Troubleshooting

### "Connection failed"
- Make sure the DTL API is running
- Check DTL_BASE_URL is correct

### "401 Unauthorized"
- Make sure CF_API_KEY is set correctly
- Verify the API key exists in the database

### "No precedents found"
- The embedding generation may take a moment
- Run the test again after a few seconds

### Semantic search not finding related decisions
- Verify embeddings are being generated (check rationale_embedding column)
- May need more seed data for better matches

## Manual Testing

If you want to test manually:

```bash
# Create a decision
curl -X POST http://localhost:5000/api/v1/dtl/decisions \
  -H "X-CF-API-Key: your-key" \
  -H "Content-Type: application/json" \
  -d '{
    "summary": "Approved 25% discount for Acme Corp",
    "choice": {"decision": "approved", "discount_percent": 25},
    "rationale": "High churn risk customer",
    "evidence": [{"evidence_type": "manual_note", "excerpt": "Customer threatened to leave"}]
  }'

# Search for precedents
curl -X POST http://localhost:5000/api/v1/dtl/precedents/search \
  -H "X-CF-API-Key: your-key" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "Customer wants a discount because they might churn"
  }'
```

## Next Steps After Testing

Once tests pass:

1. **Seed more real decisions** - 20-50 historical decisions will dramatically improve precedent matching
2. **Wire precedent queries into agents** - Have agents query DTL before making decisions
3. **Track outcomes** - Record whether decisions were successful to improve ranking
4. **Monitor usage** - Track which decision types are most queried
