FULL SOLUTION: DIRECTION-AWARE RELATIONSHIP QUERIES

We're building the proper solution, not a quick fix. This adds relationship
direction awareness to the query pipeline.

================================================================================
OVERVIEW
================================================================================

PROBLEM:
"Who reports to the CEO?" and "Who does the CEO report to?" both involve
REPORTS_TO relationship but in OPPOSITE directions. Current system doesn't
distinguish them.

SOLUTION:
Add direction field to QueryIntent. Intent detector classifies direction.
Rewrite logic uses direction field, not string pattern matching.

ARCHITECTURE:

QueryIntent {
    intent_type: "relationship"
    relationship_type: "REPORTS_TO"
    direction: "inbound" | "outbound"    # NEW
    target_role: "subordinates" | "manager"  # NEW (optional, for clarity)
}

Direction meanings:
- inbound: Entity is the TARGET. Find who points TO them.
  "Who reports to Sarah?" → Find sources of REPORTS_TO edges to Sarah
  
- outbound: Entity is the SOURCE. Find what they point TO.
  "Who does Sarah report to?" → Find targets of REPORTS_TO edges from Sarah

Add new rewrite method:
```python
def _rewrite_relationship_query(
    self,
    person_name: str,
    relationship_type: str,
    direction: str
) -> str:
    """
    Rewrite relationship query with resolved person name.
    Direction determines the query structure.
    """
    
    if relationship_type == "REPORTS_TO":
        if direction == "inbound":
            return f"Who reports to {person_name}?"
        else:  # outbound
            return f"Who does {person_name} report to?"
    
    elif relationship_type == "MANAGES":
        if direction == "inbound":
            return f"Who does {person_name} manage?"
        else:
            return f"Who manages {person_name}?"
    
    elif relationship_type == "OWNS":
        if direction == "inbound":
            return f"What does {person_name} own?"
        else:
            return f"Who owns {person_name}?"
    
    elif relationship_type == "INVESTED_IN":
        if direction == "inbound":
            return f"Who invested in {person_name}?"
        else:
            return f"What has {person_name} invested in?"
    
    else:
        # Generic fallback
        return f"What is {person_name}'s relationship to others?"
```
