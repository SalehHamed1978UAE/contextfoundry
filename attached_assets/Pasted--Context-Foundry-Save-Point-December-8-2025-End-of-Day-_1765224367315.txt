## 🎯 WHY CONTEXT FOUNDRY EXISTS

### The Problem
ADQ has **50+ portfolio companies** across healthcare, maritime, energy, aviation, infrastructure, manufacturing, and financial services. When you ask an LLM a question about ADQ operations, it either:
1. **Hallucinates** — makes up plausible-sounding but wrong answers
2. **Fails** — says "I don't have that information"

Neither is acceptable for a sovereign wealth fund making billion-dollar decisions.

### The Solution
> **"Organizational Object Permanence for AI Applications"**

Context Foundry gives AI applications **persistent awareness** of your organization — entities, relationships, rules, and history — so they can reason accurately instead of hallucinating.

### The Core Innovation
**Context Foundry refuses to hallucinate.**

When data doesn't exist, it:
- Admits uncertainty with explicit knowledge boundaries
- Says "I don't know" with 70% confidence instead of making things up
- Shows exactly what it DOES know and where the gaps are

### Tri-Memory Architecture
| Memory Layer | What It Stores | Purpose |
|--------------|----------------|---------|
| **Semantic** | Vector embeddings (1536-dim) | What concepts are SIMILAR |
| **Episodic** | Provenance, source docs, timestamps | WHERE knowledge came from, WHEN |
| **Symbolic** | Knowledge graph (entities + relationships) | What things ARE and how they CONNECT |

### The 11 Agents

**Ingestion Agents (Getting Data In)**
| Agent | Job |
|-------|-----|
| Graph Builder | Extract entities/relationships from documents → STAGING |
| Graph Loader | Load structured data into all three memory layers |

**Validation Agents (Quality Control)**
| Agent | Job |
|-------|-----|
| Staging Validator | Check STAGING data against schema rules |
| Identity Resolution | Find duplicates using weighted signals + fuzzy matching |
| Orphan Detector | Find patterns that don't fit current ontology |

**Maintenance Agents (Keeping It Healthy)**
| Agent | Job |
|-------|-----|
| Gardener | 5 passes: Decay, Promotion, Conflict Resolution, Demotion, Cleanup |

**Query Agents (Getting Knowledge Out)**
| Agent | Job |
|-------|-----|
| Retrieval | Gather context from all three memories |
| Reasoning | Generate answers, check sufficiency, detect hallucination |
| Validation | Check answers against symbolic rules |

**Ontology Agents (Schema Management)**
| Agent | Job |
|-------|-----|
| Schema Prompt Generator | Build dynamic LLM prompts from current ontology |
| Constrained Extractor | Extract only types defined in active schema |

### The Pipeline
```
Document → Graph Builder → Staging Validator → Identity Resolution
                                    ↓
                              Gardener (maintenance)
                                    ↓
              Query → Retrieval → Reasoning → Validation → Response
```

### What It Enables
- **Any AI application** can query it for grounded context
- **Board advisors** get answers with citations and confidence scores
- **Portfolio analysis** spans 50+ companies with unified understanding
- **Premisia** integration for strategic consulting with real organizational data
- **No hallucination** — if the data isn't there, the system says so

### The Vision
> "This isn't a database that returns data. It's a system that builds understanding."

Context Foundry is the **nervous system** for ADQ's AI applications.
