  But more importantly - there's a SQL bug in my query:                                                  
                                                                                                         
  d.name ILIKE '%_customer%'                                                                             
                                                                                                         
  In SQL ILIKE, the underscore _ is a wildcard that matches any single character! So %_customer% doesn't 
  literally match "_customer" - it matches "any char + customer".                                        
                                                                                                         
  Fix: Either escape the underscore or simplify the pattern:                                             
                                                                                                         
  d.name ILIKE '%customer%'  -- simpler, will match boeing_customer_profile.md
