Next milestone: Context Bundle API
This is Pillar 4 from the vision - "Deliver structured, trustworthy truth to AI."
The Context Bundle contains:
pythonclass ContextBundle:
    # Focal entities (what the query is about)
    focal_entities: List[Entity]
    
    # Dependency graph (N-hop neighborhood)
    related_entities: List[Entity]
    relationships: List[Relationship]
    
    # Provenance
    source_documents: List[DocumentReference]
    confidence_summary: ConfidenceSummary
    
    # Episodic context
    similar_incidents: List[IncidentPattern]  # "This happened before"
    recent_changes: List[ChangeEvent]         # "This changed recently"
    
    # Symbolic constraints
    applicable_rules: List[Rule]              # "These rules apply"
    
    # Knowledge boundaries
    uncertainty: List[str]                    # "We don't know X"
```

**API Endpoint:**
```
POST /api/v1/context
{
    "query": "What services are affected if Payment Database goes down?",
    "focal_entity": "Payment Database",  // optional
    "max_hops": 2,
    "include_episodic": true,
    "include_symbolic": true
}

Response:
{
    "bundle": { ... },
    "confidence": 0.87,
    "knowledge_boundaries": ["No visibility into..."],
    "provenance": { ... }
}
