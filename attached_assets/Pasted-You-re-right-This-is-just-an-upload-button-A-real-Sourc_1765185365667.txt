The Sources interface is too basic. Expand it:

1. CORPUS OVERVIEW (top of dashboard, always visible):
   - Total documents count
   - Total entities extracted
   - Total relationships
   - Documents by status: Extracted / Processing / Failed

2. RECENT ACTIVITY section:
   - Group documents by date (Today, Yesterday, Last Week, Earlier)
   - Show document name, status, entity count
   - Collapsible date groups

3. STATUS TAB improvements:
   - Table view with columns: Name, Type, Domain Detected, Status, Entities, Date
   - Filters: by status, by file type, by domain
   - Search box to find documents
   - Pagination
   - Click row to see document details

4. DOCUMENT DETAIL VIEW (when clicking a document):
   - Full metadata (upload date, size, type, domain detected, confidence)
   - Processing time
   - List of extracted entities grouped by type
   - Entity count per type
   - Actions: View in Knowledge Graph, Re-extract, Delete

5. UPLOAD section:
   - Keep drag & drop
   - Show upload progress
   - Show real-time status as documents process

Query the database for real data:
- SELECT COUNT(*) FROM platform.documents WHERE tenant_id = ?
- SELECT COUNT(*) FROM public.entities WHERE tenant_id = ?
- SELECT status, COUNT(*) FROM platform.documents GROUP BY status

Make it informative. Users should understand their corpus at a glance.
