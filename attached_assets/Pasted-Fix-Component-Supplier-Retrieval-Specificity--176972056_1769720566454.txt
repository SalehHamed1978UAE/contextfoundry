Fix Component-Supplier Retrieval Specificity                                                   
                                                                                                         
  The Problem                                                                                            
                                                                                                         
  When asking "Who provides the SAR radar?", the system returns a chunk listing ALL suppliers. The LLM   
  then incorrectly says "Raytheon and Honeywell" when only Raytheon provides SAR radar.                  
                                                                                                         
  The Fix (Two Parts)                                                                                    
                                                                                                         
  ---                                                                                                    
  Part 1: Add Component-Supplier Matching Instruction to Answer Synthesis                                
                                                                                                         
  File: src/context_foundry/agents/query_pipeline.py                                                     
                                                                                                         
  Find ANSWER_SYNTHESIS_PROMPT and add this rule to CRITICAL RULES:                                      
                                                                                                         
  CRITICAL RULES:                                                                                        
  1. ONLY use information from the retrieval results - never make up facts                               
  2. If no relationships were found, clearly state that                                                  
  3. For blast radius queries, list the affected entities with their relationship type                   
  4. Cite the relationship type and confidence for each fact                                             
  5. If the entity wasn't found, suggest checking the entity name                                        
  6. **COMPONENT-SUPPLIER MATCHING**: When asked about a specific component (e.g., "SAR radar", "flight  
  computers", "electrolyzers"), ONLY mention the supplier that provides THAT SPECIFIC component. Do NOT  
  list other suppliers from the context that provide different components.                               
     - "Who provides SAR radar?" → Only mention the supplier listed for SAR/radar                        
     - "Who provides flight computers?" → Only mention the supplier listed for flight computers          
     - If the context shows "Honeywell - Flight Computers" and "Raytheon - SAR Radar", and the question  
  asks about SAR radar, answer ONLY "Raytheon"                                                           
                                                                                                         
  ---                                                                                                    
  Part 2: Add Component-Specific Search Boost                                                            
                                                                                                         
  File: src/context_foundry/agents/retrieval_router.py                                                   
                                                                                                         
  Find the _search_documents method and add component detection:
