PART 2: UPDATE ENTITY STATUS BASED ON DOCUMENT PUBLISH STATE
═══════════════════════════════════════════════════════════════

When document is published → entities become 'trusted'
When document is unpublished → entities become 'staging'
When document is deleted → entities are deleted

Add/update column in entities if needed:
- entities.status = 'staging' | 'trusted'

═══════════════════════════════════════════════════════════════
PART 3: API ENDPOINTS
═══════════════════════════════════════════════════════════════

POST /api/documents/<id>/publish
- Sets published=TRUE, published_at=NOW(), published_by=user
- Updates associated entities to status='trusted'
- Returns success

POST /api/documents/<id>/unpublish  
- Sets published=FALSE
- Updates associated entities to status='staging'
- Returns success

POST /api/documents/<id>/reject
- Soft delete: Sets status='rejected', published=FALSE
- Deletes associated entities and relationships
- Returns success

DELETE /api/documents/<id>
- Hard delete: Removes document, entities, relationships
- Returns success

POST /api/documents/<id>/re-extract
- Sets status='queued', published=FALSE
- Deletes existing entities/relationships
- Re-queues for extraction
- Returns success

GET /api/documents/<id>/details
- Returns document metadata + list of entities grouped by type
