CHECK 2: IS SOURCE CONTENT PRESENT IN CHUNKS?
================================================================================
```sql
-- Bug 1: Is CloudMatrix investment info in the chunks?
SELECT d.name, LEFT(c.content, 500) as content_preview
FROM chunks c
JOIN documents d ON c.document_id = d.id
WHERE d.tenant_id = (SELECT id FROM vaults WHERE name = 'TechVentures')
  AND (c.content ILIKE '%CloudMatrix%' OR c.content ILIKE '%HealthSync%')
LIMIT 5;

-- Bug 2: Is compensation info in Launchpad chunks?
SELECT d.name, LEFT(c.content, 500) as content_preview
FROM chunks c
JOIN documents d ON c.document_id = d.id
WHERE d.tenant_id = (SELECT id FROM vaults WHERE name = 'Launchpad Ventures')
  AND (c.content ILIKE '%salary%' OR c.content ILIKE '%compensation%' OR c.content ILIKE '%bonus%')
LIMIT 5;

-- Bug 3: Is reporting structure in TechVentures chunks?
SELECT d.name, LEFT(c.content, 500) as content_preview
FROM chunks c
JOIN documents d ON c.document_id = d.id
WHERE d.tenant_id = (SELECT id FROM vaults WHERE name = 'TechVentures')
  AND (c.content ILIKE '%reports to%' OR c.content ILIKE '%reporting to%')
LIMIT 5;
```

If content exists → LLM/extraction missed it
If no content → Document doesn't have this info (not a bug)
