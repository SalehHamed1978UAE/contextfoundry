# Test Runner State Machine Specification

## 1. States (Enum)

```python
class TestRunStatus(Enum):
    IDLE = 'idle'              # No test running, ready to start
    CREATING_VAULT = 'creating_vault'  # Fresh mode: vault being created
    UPLOADING = 'uploading'    # Documents being uploaded to vault
    EXTRACTING = 'extracting'  # Waiting for extraction to complete
    RUNNING_QA = 'running_qa'  # QA questions being executed
    COMPLETE = 'complete'      # Test finished successfully
    FAILED = 'failed'          # Test failed with error
    INTERRUPTED = 'interrupted' # Test was interrupted (server restart, manual stop)
```

## 2. Valid Transitions Table

| From | To | Trigger |
|------|----|---------|
| IDLE | CREATING_VAULT | Fresh mode start |
| IDLE | UPLOADING | Auto mode start (vault already exists) |
| CREATING_VAULT | UPLOADING | Vault created successfully |
| CREATING_VAULT | FAILED | Vault creation failed |
| UPLOADING | EXTRACTING | All files uploaded |
| UPLOADING | FAILED | Upload failed |
| EXTRACTING | RUNNING_QA | Extraction complete (entities > 0, jobs done) |
| EXTRACTING | FAILED | Extraction failed or timeout |
| RUNNING_QA | COMPLETE | All questions answered |
| RUNNING_QA | FAILED | Unrecoverable error |
| ANY except COMPLETE | INTERRUPTED | Server restart with stale heartbeat (>5 min) OR manual stop |
| INTERRUPTED | RUNNING_QA | Resume (only valid if was in RUNNING_QA) |
| ANY | IDLE | Reset endpoint called |

**Invalid transitions should raise an exception:**
```python
def transition_to(run_id: int, new_status: TestRunStatus):
    run = TestRun.query.get(run_id)
    old_status = TestRunStatus(run.status)
    
    if not is_valid_transition(old_status, new_status):
        raise InvalidStateTransition(f"Cannot go from {old_status} to {new_status}")
    
    run.status = new_status.value
    run.updated_at = datetime.utcnow()
    run.heartbeat_at = datetime.utcnow()
    db.session.commit()
    
    log.info(f"Test run {run_id}: {old_status.value} → {new_status.value}")
```

## 3. Database Schema (test_runs table)

```sql
CREATE TABLE test_runs (
    id SERIAL PRIMARY KEY,
    status VARCHAR(20) NOT NULL DEFAULT 'idle',  -- From TestRunStatus enum
    vault_id UUID NULL,  -- NULL until vault is created
    vault_name VARCHAR(255) NULL,
    mode VARCHAR(10) NOT NULL,  -- 'fresh' or 'auto'
    
    -- Progress tracking
    questions_total INTEGER DEFAULT 0,
    questions_passed INTEGER DEFAULT 0,
    questions_failed INTEGER DEFAULT 0,
    current_question INTEGER DEFAULT 0,
    
    -- Timing
    created_at TIMESTAMP DEFAULT NOW(),
    started_at TIMESTAMP NULL,  -- When QA actually started
    completed_at TIMESTAMP NULL,
    heartbeat_at TIMESTAMP NULL,  -- Updated every 30 seconds during run
    
    -- Error tracking
    error_message TEXT NULL,
    
    -- Results
    results_file VARCHAR(255) NULL
);
```

```python
# In api.py startup - mark stale tests as interrupted
def startup_cleanup():
    stale_threshold = datetime.utcnow() - timedelta(minutes=5)
    
    stale_runs = TestRun.query.filter(
        TestRun.status.in_(['creating_vault', 'uploading', 'extracting', 'running_qa']),
        TestRun.heartbeat_at < stale_threshold
    ).all()
    
    for run in stale_runs:
        run.status = TestRunStatus.INTERRUPTED.value
        run.error_message = "Interrupted: Server restarted with stale heartbeat"
    
    db.session.commit()
```
