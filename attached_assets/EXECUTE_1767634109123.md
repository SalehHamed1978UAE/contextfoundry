## Execution Steps

### Step 1: Create new tenant

```python
DEMO2_TENANT_ID = "demo-alshifa-00000000-0000-0000-0000-000000000002"
```

### Step 2: Ingest documents

```python
import os
from context_foundry.core import ContextFoundry

cf = ContextFoundry(tenant_id=DEMO2_TENANT_ID)

docs_path = "/home/claude/test2_docs/"  # or wherever docs are
for filename in os.listdir(docs_path):
    if filename.endswith('.md'):
        with open(os.path.join(docs_path, filename), 'r') as f:
            content = f.read()
        cf.ingest_document(content=content, filename=filename)
        print(f"Ingested: {filename}")
```

### Step 3: Wait for extraction + verify

```python
# Check counts

print(f"Entities: {stats.get('entity_count')}")
print(f"Relationships: {stats.get('relationship_count')}")
```
