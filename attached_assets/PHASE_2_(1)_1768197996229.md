\================================================================================  
BACKGROUND — WHAT WE DISCOVERED  
\================================================================================

We ran the E2E test twice with identical code and documents. Results:

RUN 1 vs RUN 2 EXTRACTION COUNTS:  
| Vault              | RUN 1 Entities | RUN 2 Entities | Difference |  
|--------------------|----------------|----------------|------------|  
| TechVentures       | 174            | 123            | \-51        |  
| Riverside          | 40             | 90             | \+50        |  
| Titan              | 78             | 48             | \-30        |  
| Launchpad          | 119            | 106            | \-13        |

Same documents. Same code. Wildly different extraction results.

CONSISTENT BUGS (appeared in both runs):  
1\. "What is the CEO's salary?" (TechVentures) → Returns "The CEO is Sarah Chen" instead of "$850,000"  
2\. "Who reports to the CEO?" (TechVentures) → Returns CEO's name instead of list of reports  
3\. "Who is the CMO?" (Riverside) → Returns "does not specify" even though data exists  
4\. CloudAI not extracted (Launchpad) → Entity in document but not in graph  
5\. "75th percentile" extracted as investment target → Garbage relationship

ROOT CAUSE INVESTIGATION FINDINGS:

1\. COMPENSATION NOT LINKED:  
   \- Sarah Chen entity exists  
   \- $850,000 entity exists    
   \- But NO relationship connecting them  
   \- Riverside has 18 RECEIVES\_COMPENSATION relationships; TechVentures has 0

2\. LLM EXTRACTION IS NON-DETERMINISTIC:  
   \- Same prompt, different runs \= different outputs  
   \- This is inherent to LLMs, not a bug we can fix  
   \- Temperature=0 doesn't guarantee determinism (GPU numerics, batching vary)

3\. NO VALIDATION ON EXTRACTION:  
   \- System accepts whatever LLM returns  
   \- No check that compensation is linked to people  
   \- No check that relationship targets are valid types  
   \- "75th percentile" as INVESTED\_IN target was never flagged

\================================================================================  
THE SOLUTION — DEFENSE IN DEPTH  
\================================================================================

We cannot make LLM extraction deterministic. But we can BUILD SYSTEMS THAT  
DON'T REQUIRE PERFECTION.

NEW ARCHITECTURE:

Document → LLM Extraction (70-90% coverage, variable)  
        → Post-Processor (catches obvious patterns LLM missed)  
        → Gap Detector (validates semantic correctness)  
        → Final output (more complete, validated)

This is how production ML systems work. You validate outputs, not trust them.

1\. ROLE\_PATTERNS \- Regex patterns for role extraction:

   \- "John reports to Sarah"  
   \- "Sarah manages John"

3\. COMPENSATION\_PATTERNS \- Regex for compensation:

4\. ExtractionPostProcessor class:  
   \- process(document\_text, existing\_entities, existing\_relationships)  
   \- Returns new entities and relationships the LLM missed  
   \- Only adds if not already present (no duplicates)

    def \_build\_entity\_name\_set(self, entities: List\[Dict\]) \-\> Set\[str\]:  
        names \= set()  
        for e in entities:  
            name \= e.get('name') or e.get('canonical\_name', '')  
            if name:  
                names.add(name.lower().strip())  
        return names  
      
    def \_build\_relationship\_keys(self, relationships: List\[Dict\]) \-\> Set\[Tuple\[str, str, str\]\]:  
        keys \= set()  
        for r in relationships:  
            source \= (r.get('source\_name') or '').lower().strip()  
            target \= (r.get('target\_name') or '').lower().strip()  
            rel\_type \= (r.get('relationship\_type') or r.get('type', '')).upper().strip()  
            if source and target and rel\_type:  
                keys.add((source, target, rel\_type))  
        return keys  
      
    def \_normalize\_role(self, role: str) \-\> str:  
        role \= role.strip()  
        role\_upper \= role.upper()  
        if role\_upper in ROLE\_ABBREVIATIONS:  
            return ROLE\_ABBREVIATIONS\[role\_upper\]  
        return role  
      
    def \_is\_valid\_person\_name(self, name: str) \-\> bool:  
        words \= name.split()  
        if len(words) \< 2 or len(words) \> 4:  
            return False  
        invalid\_words \= {'the', 'our', 'their', 'and', 'or', 'for', 'to', 'of', 'in', 'on', 'is', 'are'}  
        if any(w.lower() in invalid\_words for w in words):  
            return False  
        return all(word\[0\].isupper() for word in words)  
      
    def \_extract\_role\_relationships(  
        self, text: str, existing\_names: Set\[str\], existing\_rels: Set\[Tuple\]  
    ) \-\> Tuple\[List\[ExtractedRelationship\], List\[Dict\]\]:  
        relationships \= \[\]  
        new\_entities \= \[\]  
        seen\_pairs \= set()  
          
        for pattern in self.role\_patterns:  
            try:  
                for match in re.finditer(pattern.pattern, text, re.IGNORECASE):  
                    person\_name \= match.group(pattern.person\_group).strip()  
                    role\_title \= match.group(pattern.role\_group).strip()  
                      
                    if not self.\_is\_valid\_person\_name(person\_name):  
                        continue  
                      
                    role\_title \= self.\_normalize\_role(role\_title)  
                    pair\_key \= (person\_name.lower(), role\_title.lower())  
                      
                    if pair\_key in seen\_pairs:  
                        continue  
                    seen\_pairs.add(pair\_key)  
                      
                    rel\_key \= (person\_name.lower(), role\_title.lower(), "HOLDS\_POSITION")  
                    if rel\_key in existing\_rels:  
                        continue  
                      
                    relationships.append(ExtractedRelationship(  
                        relationship\_type="HOLDS\_POSITION",  
                        source\_name=person\_name,  
                        target\_name=role\_title,  
                        confidence=pattern.confidence,  
                        pattern\_name=pattern.name,  
                        source\_text=match.group(0)  
                    ))  
                      
                    if person\_name.lower() not in existing\_names:  
                        new\_entities.append({"name": person\_name, "entity\_type": "PERSON", "source": "post\_processor"})  
                        existing\_names.add(person\_name.lower())  
                      
                    if role\_title.lower() not in existing\_names:  
                        new\_entities.append({"name": role\_title, "entity\_type": "JOB\_TITLE", "source": "post\_processor"})  
                        existing\_names.add(role\_title.lower())  
            except Exception as e:  
                print(f"\[PostProcessor\] Pattern '{pattern.name}' failed: {e}")  
          
        return relationships, new\_entities  
      
    def \_extract\_reporting\_relationships(  
        self, text: str, existing\_names: Set\[str\], existing\_rels: Set\[Tuple\]  
    ) \-\> List\[ExtractedRelationship\]:  
        relationships \= \[\]  
        seen\_pairs \= set()  
          
        for pattern, confidence, rel\_type in self.reporting\_patterns:  
            try:  
                for match in re.finditer(pattern, text, re.IGNORECASE):  
                    if rel\_type \== "reports\_to":  
                        subordinate \= match.group(1).strip()  
                        manager \= match.group(2).strip()  
                    else:  
                        manager \= match.group(1).strip()  
                        subordinate \= match.group(2).strip()  
                      
                    pair\_key \= (subordinate.lower(), manager.lower())  
                    if pair\_key in seen\_pairs:  
                        continue  
                    seen\_pairs.add(pair\_key)  
                      
                    rel\_key \= (subordinate.lower(), manager.lower(), "REPORTS\_TO")  
                    if rel\_key in existing\_rels:  
                        continue  
                      
                    relationships.append(ExtractedRelationship(  
                        relationship\_type="REPORTS\_TO",  
                        source\_name=subordinate,  
                        target\_name=manager,  
                        confidence=confidence,  
                        pattern\_name="reporting\_pattern",  
                        source\_text=match.group(0)  
                    ))  
            except Exception as e:  
                print(f"\[PostProcessor\] Reporting pattern failed: {e}")  
          
        return relationships  
      
    def \_extract\_compensation\_relationships(  
        self, text: str, existing\_names: Set\[str\], existing\_rels: Set\[Tuple\]  
    ) \-\> List\[ExtractedRelationship\]:  
        relationships \= \[\]  
        seen\_names \= set()  
          
        for pattern, rel\_type, confidence in self.compensation\_patterns:  
            try:  
                for match in re.finditer(pattern, text, re.IGNORECASE):  
                    groups \= match.groups()  
                      
                    if rel\_type \== "compensation\_reverse":  
                        amount \= groups\[0\].strip()  
                        person\_name \= groups\[1\].strip()  
                    else:  
                        person\_name \= groups\[0\].strip()  
                        amount \= groups\[1\].strip()  
                      
                    if not self.\_is\_valid\_person\_name(person\_name):  
                        continue  
                      
                    if person\_name.lower() in seen\_names:  
                        continue  
                    seen\_names.add(person\_name.lower())  
                      
                    rel\_key \= (person\_name.lower(), amount, "HAS\_COMPENSATION")  
                    if rel\_key in existing\_rels:  
                        continue  
                      
                    relationships.append(ExtractedRelationship(  
                        relationship\_type="HAS\_COMPENSATION",  
                        source\_name=person\_name,  
                        target\_name=f"${amount}",  
                        confidence=confidence,  
                        pattern\_name="compensation\_pattern",  
                        source\_text=match.group(0)  
                    ))  
            except Exception as e:  
                print(f"\[PostProcessor\] Compensation pattern failed: {e}")  
          
        return relationships

"""  
Extraction Gap Detector for Context Foundry.  
Detects extraction gaps and validates relationship targets.  
"""

from dataclasses import dataclass, field  
from datetime import datetime  
from typing import Dict, List, Optional, Set  
from enum import Enum  
from sqlalchemy.orm import Session  
from sqlalchemy import text

class GapSeverity(str, Enum):  
    CRITICAL \= "critical"  
    WARNING \= "warning"  
    INFO \= "info"

class GapType(str, Enum):  
    PERSON\_WITHOUT\_ROLE \= "person\_without\_role"  
    ORPHAN\_ROLE \= "orphan\_role"  
    MISSING\_REPORTS\_TO \= "missing\_reports\_to"  
    COMPENSATION\_WITHOUT\_ROLE \= "compensation\_without\_role"  
    PERSON\_WITHOUT\_ORGANIZATION \= "person\_without\_organization"  
    INVALID\_RELATIONSHIP\_TARGET \= "invalid\_relationship\_target"

\# Valid target types for each relationship type  
RELATIONSHIP\_TARGET\_CONSTRAINTS \= {  
    "INVESTED\_IN": \["ORGANIZATION", "COMPANY", "STARTUP", "PORTFOLIO\_COMPANY"\],  
    "HAS\_INVESTMENT": \["ORGANIZATION", "COMPANY", "STARTUP", "PORTFOLIO\_COMPANY"\],  
    "HOLDS\_POSITION": \["JOB\_TITLE", "ROLE", "POSITION"\],  
    "HAS\_ROLE": \["JOB\_TITLE", "ROLE", "POSITION"\],  
    "REPORTS\_TO": \["PERSON", "EMPLOYEE", "EXECUTIVE"\],  
    "MANAGED\_BY": \["PERSON", "EMPLOYEE", "EXECUTIVE"\],  
    "WORKS\_AT": \["ORGANIZATION", "COMPANY", "DEPARTMENT", "TEAM"\],  
    "EMPLOYED\_BY": \["ORGANIZATION", "COMPANY", "DEPARTMENT", "TEAM"\],  
    "RECEIVES\_COMPENSATION": \["COMPENSATION", "SALARY", "AMOUNT", "MONETARY\_VALUE"\],  
    "HAS\_COMPENSATION": \["COMPENSATION", "SALARY", "AMOUNT", "MONETARY\_VALUE"\],  
}

@dataclass  
class ExtractionGap:  
    gap\_type: GapType  
    severity: GapSeverity  
    entity\_id: str  
    entity\_name: str  
    entity\_type: str  
    description: str  
    suggested\_fix: str \= ""  
    detected\_at: datetime \= field(default\_factory=datetime.utcnow)  
    document\_id: Optional\[str\] \= None

@dataclass  
class GapDetectionResult:  
    gaps: List\[ExtractionGap\]  
    detection\_time\_ms: float \= 0  
      
    @property  
    def critical\_count(self) \-\> int:  
        return sum(1 for g in self.gaps if g.severity \== GapSeverity.CRITICAL)  
      
    @property  
    def warning\_count(self) \-\> int:  
        return sum(1 for g in self.gaps if g.severity \== GapSeverity.WARNING)  
      
    @property  
    def info\_count(self) \-\> int:  
        return sum(1 for g in self.gaps if g.severity \== GapSeverity.INFO)

class ExtractionGapDetector:  
    """Detects gaps and validates extraction results."""  
      
    def \_\_init\_\_(self, session: Session, tenant\_id: Optional\[str\] \= None):  
        self.session \= session  
        self.tenant\_id \= tenant\_id  
      
    def detect\_all(self, document\_id: Optional\[str\] \= None) \-\> GapDetectionResult:  
        import time  
        start \= time.time()  
          
        gaps \= \[\]  
          
        \# Load entities and relationships  
        entities \= self.\_get\_entities(document\_id)  
        relationships \= self.\_get\_relationships(document\_id)  
          
        \# Build lookup structures  
        entity\_by\_id \= {str(e.id): e for e in entities}  
        person\_ids \= {str(e.id) for e in entities if e.entity\_type and e.entity\_type.upper() \== "PERSON"}  
          
        \# Check for invalid relationship targets  
        for rel in relationships:  
            rel\_type \= rel.relationship\_type.upper() if rel.relationship\_type else ""  
            target\_id \= str(rel.target\_id) if rel.target\_id else None  
              
            if not target\_id or rel\_type not in RELATIONSHIP\_TARGET\_CONSTRAINTS:  
                continue  
              
            target\_entity \= entity\_by\_id.get(target\_id)  
            if not target\_entity:  
                continue  
              
            valid\_types \= RELATIONSHIP\_TARGET\_CONSTRAINTS\[rel\_type\]  
            target\_type \= target\_entity.entity\_type.upper() if target\_entity.entity\_type else "UNKNOWN"  
              
            if target\_type not in \[t.upper() for t in valid\_types\]:  
                source\_entity \= entity\_by\_id.get(str(rel.source\_id))  
                source\_name \= source\_entity.name if source\_entity else "Unknown"  
                  
                gaps.append(ExtractionGap(  
                    gap\_type=GapType.INVALID\_RELATIONSHIP\_TARGET,  
                    severity=GapSeverity.CRITICAL,  
                    entity\_id=target\_id,  
                    entity\_name=target\_entity.name,  
                    entity\_type=target\_type,  
                    description=f"'{source\_name}' \--\[{rel\_type}\]--\> '{target\_entity.name}' has invalid target type '{target\_type}'. Expected: {', '.join(valid\_types)}",  
                    suggested\_fix=f"Remove or fix this relationship. {rel\_type} should target {'/'.join(valid\_types\[:3\])}"  
                ))  
          
        result \= GapDetectionResult(gaps=gaps)  
        result.detection\_time\_ms \= (time.time() \- start) \* 1000  
          
        return result  
      
    def \_get\_entities(self, document\_id: Optional\[str\]) \-\> List:  
        try:  
            query \= "SELECT id, name, entity\_type, properties FROM entities WHERE tenant\_id \= :tid"  
            params \= {"tid": self.tenant\_id}  
              
            if document\_id:  
                query \+= " AND source\_document\_id \= :doc\_id"  
                params\["doc\_id"\] \= document\_id  
              
            result \= self.session.execute(text(query), params)  
              
            class EntityRow:  
                def \_\_init\_\_(self, row):  
                    self.id \= row\[0\]  
                    self.name \= row\[1\]  
                    self.entity\_type \= row\[2\]  
                    self.properties \= row\[3\]  
              
            return \[EntityRow(row) for row in result.fetchall()\]  
        except Exception as e:  
            print(f"\[GapDetector\] Failed to load entities: {e}")  
            return \[\]  
      
    def \_get\_relationships(self, document\_id: Optional\[str\]) \-\> List:  
        try:  
            query \= "SELECT id, source\_id, target\_id, relationship\_type FROM relationships WHERE tenant\_id \= :tid"  
            params \= {"tid": self.tenant\_id}  
              
            if document\_id:  
                query \+= " AND source\_document\_id \= :doc\_id"  
                params\["doc\_id"\] \= document\_id  
              
            result \= self.session.execute(text(query), params)  
              
            class RelRow:  
                def \_\_init\_\_(self, row):  
                    self.id \= row\[0\]  
                    self.source\_id \= row\[1\]  
                    self.target\_id \= row\[2\]
