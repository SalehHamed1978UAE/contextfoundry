```python
        "classifier_version": CLASSIFIER_VERSION,

```

Do not allow `classify_with_fallback("")` to write `"please_provide_the_document_you_would_like_me_to_analyze"` into `document_type`. Replit already surfaced that behavior as an upstream issue, and the wrapper is the right place to protect the production path. 

## 3. Partial-failure status

**Escalate to `failed` when `primary_domain is None`.**

If the domain classifier fails, returns `unknown`, produces zero confidence, or cannot produce a canonical domain, the classification record is not complete enough to be `ok`.

Use:

```text
classification_status = failed
primary_domain = None
document_type = None
classification_error = <specific reason>
```

Do not mark it `ok` just because `document_type` succeeded. Domain classification is the load-bearing output for Piece 1.

This keeps the semantic contract clean:

```text
ok = both domain and document_type classified successfully
failed = classification attempted but not usable
unclassified = never classified
```
