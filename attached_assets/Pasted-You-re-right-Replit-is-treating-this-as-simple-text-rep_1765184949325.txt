**CONTEXT FOUNDRY HAS TWO MODULES:**

| Module | URL | Purpose |
|--------|-----|---------|
| **Sources** | 4a3m.riker.replit.dev (Platform) | Where users PUT information in |
| **Knowledge** | context-foundry.replit.app (Brain) | Where users GET insights out |

These are TWO SEPARATE APPLICATIONS that should feel like ONE SYSTEM.

---

**USER JOURNEY 1: New User Onboarding**

```
User logs in via Google OAuth
    ↓
Lands on Sources module (Platform)
    ↓
Sees unified header: [📥 Sources*] [🧠 Knowledge]
    ↓
"Sources" is highlighted because they're in Sources
    ↓
Uploads their first document
    ↓
Sees document in Status tab: "Processing..."
    ↓
After 60 seconds, status changes to "Extracted"
    ↓
Clicks "Knowledge" in header
    ↓
Opens Brain (context-foundry.replit.app) in same or new tab
    ↓
Sees their extracted entities in Knowledge Graph
    ↓
Asks a question, gets answer with citations
```

---

**USER JOURNEY 2: Daily User — Adding Documents**

```
User logs in
    ↓
Sees header: [📥 Sources*] [🧠 Knowledge]
    ↓
Clicks "Upload" sub-tab
    ↓
Drags 5 documents
    ↓
Clicks "Status" sub-tab to monitor progress
    ↓
Sees: doc1.pdf ✅ Extracted, doc2.pdf ⏳ Processing...
    ↓
When done, clicks "Knowledge" in header
    ↓
Explores new entities in Brain
```

---

**USER JOURNEY 3: Daily User — Querying Knowledge**

```
User logs in
    ↓
Sees header: [📥 Sources] [🧠 Knowledge*]
    ↓
Clicks "Knowledge" immediately (skips Sources)
    ↓
Opens Brain dashboard
    ↓

    ↓

    ↓
```
