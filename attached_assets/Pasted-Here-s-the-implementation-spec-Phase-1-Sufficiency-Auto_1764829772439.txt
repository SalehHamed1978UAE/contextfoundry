Phase 2: Quadrant Confidence (Week 2-3)
Replace the entity-not-found guard with quadrant logic:
pythondef calculate_confidence(bundle: ContextBundle, sufficiency: str) -> float:
    entity_found = bundle.target_entity_found
    has_docs = len(bundle.episodic_documents) > 0 and bundle.episodic_documents[0].get('similarity', 0) > 0.5
    
    # Quadrant base scores
    if entity_found and has_docs:
        base = 0.90  # Best case
    elif entity_found and not has_docs:
        base = 0.70  # Graph only
    elif not entity_found and has_docs:
        base = 0.65  # Topic-centric (YOUR FAILURE CASE → NOW WORKS)
    else:
        base = 0.10  # No evidence
    
    # Adjust by sufficiency
    if sufficiency == "SUFFICIENT":
        return min(base + 0.10, 0.95)
    elif sufficiency == "PARTIAL":
        return base * 0.8
    else:  # INSUFFICIENT
        return min(base, 0.20)

Phase 3: Entity Density Scoring (Week 3-4)
For topic-centric queries, score proxy grounding:
pythondef calculate_entity_density(documents: list, known_entities: set) -> float:
    """
    How many known entities are mentioned in retrieved docs?
    High density = proxy grounding = higher confidence
    """
    mentioned_entities = extract_entities_from_text(documents)
    known_mentions = mentioned_entities.intersection(known_entities)
    
    if not mentioned_entities:
        return 0.0
    
    return len(known_mentions) / len(mentioned_entities)

Why This Works
The research consensus is clear:

Confidence should be determined by evidence quality and sufficiency, not by entity existence.

Your knowledge graph is valuable for entity-centric queries. But documents can answer topic-centric queries when a sufficiency check validates they actually contain the answer.
The sufficiency autorater is the missing piece. It asks the right question: "Can I answer this?" instead of "Does this entity exist?"
