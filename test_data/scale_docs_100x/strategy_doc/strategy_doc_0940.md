# Hiring Priorities Strategy

**Author:** Emerson Wilson
**Last Updated:** 2025-10-02
**Status:** Deprecated

## Executive Summary

This document outlines the strategic approach to hiring priorities for the upcoming quarter. Key stakeholders include Data Team and Platform Team.

## Background

The need for hiring priorities has become increasingly apparent as Auth Service faces missing documentation. Sage Robinson initially raised this concern in Q1.

## Proposed Approach

- The discussion around hiring priorities highlighted tensions between speed and stability.
- Sydney Clark proposed that we should prioritize hiring priorities before Q4.
- Cameron Davis noted that Checkout Service is currently experiencing missing documentation.
- Sydney Clark recommended a proof-of-concept for hiring priorities using Shipping Service.
- Alex Rivera recommended a proof-of-concept for hiring priorities using User Service.
- The team discussed the impact of hiring priorities on Shipping Service.

## Timeline

- Phase 1 (Week 1-2): Planning and requirements
- Phase 2 (Week 3-6): Implementation
- Phase 3 (Week 7-8): Testing and rollout

- deployment failures may impact timeline
