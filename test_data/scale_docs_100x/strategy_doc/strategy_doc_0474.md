# Caching Strategy Strategy

**Author:** Tatum Lewis
**Last Updated:** 2025-09-21
**Status:** Draft

## Executive Summary

This document outlines the strategic approach to caching strategy for the upcoming quarter. Key stakeholders include Growth Team and Backend Team.

## Background

The need for caching strategy has become increasingly apparent as API Gateway faces configuration drift. Taylor Kim initially raised this concern in Q2.

## Proposed Approach

- Finley Moore suggested involving SRE Team in the caching strategy initiative.
- Riley Garcia presented data showing improvements in Checkout Service after implementing caching strategy.
- Riley Garcia recommended a proof-of-concept for caching strategy using Cache Layer.
- Blake Adams noted that Shipping Service is currently experiencing resource exhaustion.

## Timeline

- Phase 1 (Week 1-2): Planning and requirements
- Phase 2 (Week 3-6): Implementation
- Phase 3 (Week 7-8): Testing and rollout

- Resource constraints in Backend Team
