# Hiring Priorities Strategy

**Author:** Mia White
**Last Updated:** 2025-11-05
**Status:** In Review

## Executive Summary

This document outlines the strategic approach to hiring priorities for the upcoming quarter. Key stakeholders include DevOps Team and Data Team.

## Background

The need for hiring priorities has become increasingly apparent as Email Service faces latency issues. Logan Jackson initially raised this concern in Q3.

## Proposed Approach

- Sage Robinson presented data showing improvements in Recommendation Engine after implementing hiring priorities.
- Sage Robinson recommended a proof-of-concept for hiring priorities using Auth Service.
- Harper Taylor suggested involving Mobile Team in the hiring priorities initiative.
- The team discussed the impact of hiring priorities on Shipping Service.
- The team discussed the impact of hiring priorities on Search Service.
- Harper Taylor noted that Payment Service is currently experiencing deployment failures.
- There was significant debate about hiring priorities. Emerson Wilson advocated for a phased approach.

## Timeline

- Phase 1 (Week 1-2): Planning and requirements
- Phase 2 (Week 3-6): Implementation
- Phase 3 (Week 7-8): Testing and rollout

## Risks and Mitigations

- timeout errors may impact timeline
- Resource constraints in Security Team
- Dependencies on SMS Gateway
