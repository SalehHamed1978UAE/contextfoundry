# Hiring Priorities Strategy

**Author:** Jamie Anderson
**Last Updated:** 2025-08-13

## Executive Summary

This document outlines the strategic approach to hiring priorities for the upcoming quarter. Key stakeholders include DevOps Team and Data Team.

## Background

The need for hiring priorities has become increasingly apparent as Auth Service faces scaling bottlenecks. Blake Adams initially raised this concern in Q1.

## Proposed Approach

- There was significant debate about hiring priorities. Jordan Lee advocated for a phased approach.
- Parker Harris suggested involving QA Team in the hiring priorities initiative.
- According to Taylor Kim, we need to address timeout errors before proceeding with hiring priorities.
- The team discussed the impact of hiring priorities on Cache Layer.
- Jordan Lee suggested involving Frontend Team in the hiring priorities initiative.

## Timeline

- Phase 2 (Week 3-6): Implementation
