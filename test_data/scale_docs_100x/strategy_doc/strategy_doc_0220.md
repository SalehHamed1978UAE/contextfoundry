# Vendor Evaluation Strategy

**Author:** Sage Robinson
**Last Updated:** 2025-10-01
**Status:** In Review

## Executive Summary

This document outlines the strategic approach to vendor evaluation for the upcoming quarter. Key stakeholders include DevOps Team and Security Team.

## Background

The need for vendor evaluation has become increasingly apparent as Inventory Service faces latency issues. Harper Taylor initially raised this concern in Q1.

## Proposed Approach

- Kendall Thomas presented data showing improvements in Cache Layer after implementing vendor evaluation.
- According to Dakota Miller, we need to address resource exhaustion before proceeding with vendor evaluation.
- According to Avery Brown, we need to address data inconsistency before proceeding with vendor evaluation.
- Avery Brown recommended a proof-of-concept for vendor evaluation using Order Service.
- The discussion around vendor evaluation highlighted tensions between speed and stability.
- Harper Taylor proposed that we should prioritize vendor evaluation before Q4.
- Harper Taylor suggested involving Data Team in the vendor evaluation initiative.
- Avery Brown recommended a proof-of-concept for vendor evaluation using Inventory Service.
