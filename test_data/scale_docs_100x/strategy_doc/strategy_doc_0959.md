# Team Restructuring Strategy

**Author:** Jordan Lee
**Last Updated:** 2025-06-30
**Status:** Draft

## Executive Summary

This document outlines the strategic approach to team restructuring for the upcoming quarter. Key stakeholders include SRE Team and Security Team.

## Background

The need for team restructuring has become increasingly apparent as Notification Service faces technical debt. Taylor Kim initially raised this concern in Q2.

## Proposed Approach

- Drew Patel proposed that we should prioritize team restructuring before Q4.
- According to Casey Martinez, we need to address security vulnerabilities before proceeding with team restructuring.
- Casey Martinez noted that Checkout Service is currently experiencing latency issues.
- Casey Martinez suggested involving Security Team in the team restructuring initiative.

## Timeline

- Phase 2 (Week 3-6): Implementation
- Phase 3 (Week 7-8): Testing and rollout
