# Microservices Refactoring Strategy

**Author:** Avery Brown
**Last Updated:** 2025-09-19
**Status:** Approved

## Executive Summary

This document outlines the strategic approach to microservices refactoring for the upcoming quarter. Key stakeholders include SRE Team and Backend Team.

## Background

The need for microservices refactoring has become increasingly apparent as Payment Service faces security vulnerabilities. Finley Moore initially raised this concern in Q3.

## Proposed Approach

- The team discussed the impact of microservices refactoring on Inventory Service.
- Avery Brown suggested involving Infrastructure Team in the microservices refactoring initiative.
- There was significant debate about microservices refactoring. Taylor Kim advocated for a phased approach.
- The team discussed the impact of microservices refactoring on SMS Gateway.
- The discussion around microservices refactoring highlighted tensions between speed and stability.
- According to Finley Moore, we need to address security vulnerabilities before proceeding with microservices refactoring.
- Taylor Kim recommended a proof-of-concept for microservices refactoring using Email Service.
- The team discussed the impact of microservices refactoring on Inventory Service.
