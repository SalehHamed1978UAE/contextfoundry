# Hiring Priorities Strategy

**Author:** Alex Rivera
**Last Updated:** 2025-10-26
**Status:** Approved

## Executive Summary

This document outlines the strategic approach to hiring priorities for the upcoming quarter. Key stakeholders include Mobile Team and DevOps Team.

## Background

The need for hiring priorities has become increasingly apparent as Fraud Detection faces missing documentation. Riley Garcia initially raised this concern in Q1.

## Proposed Approach

- Dakota Miller proposed that we should prioritize hiring priorities before Q4.
- Riley Garcia recommended a proof-of-concept for hiring priorities using Order Service.
- According to Alex Rivera, we need to address error rates increasing before proceeding with hiring priorities.
- Logan Jackson presented data showing improvements in Auth Service after implementing hiring priorities.
- The team discussed the impact of hiring priorities on SMS Gateway.
- There was significant debate about hiring priorities. Riley Garcia advocated for a phased approach.
- Riley Garcia noted that Inventory Service is currently experiencing missing documentation.

## Timeline

- Phase 1 (Week 1-2): Planning and requirements
- Phase 2 (Week 3-6): Implementation
- Phase 3 (Week 7-8): Testing and rollout
