# Budget Allocation Strategy

**Author:** Reese Martin
**Last Updated:** 2025-06-21
**Status:** Approved

## Executive Summary

This document outlines the strategic approach to budget allocation for the upcoming quarter. Key stakeholders include Backend Team and Mobile Team.

## Background

The need for budget allocation has become increasingly apparent as Search Service faces latency issues. Quinn Thompson initially raised this concern in Q3.

## Proposed Approach

- According to Logan Jackson, we need to address configuration drift before proceeding with budget allocation.
- Avery Brown proposed that we should prioritize budget allocation before Q4.
- The discussion around budget allocation highlighted tensions between speed and stability.
- Avery Brown recommended a proof-of-concept for budget allocation using Notification Service.
- The team discussed the impact of budget allocation on Email Service.
- Logan Jackson recommended a proof-of-concept for budget allocation using Inventory Service.

## Timeline

- Phase 1 (Week 1-2): Planning and requirements
- Phase 2 (Week 3-6): Implementation
- Phase 3 (Week 7-8): Testing and rollout

- data inconsistency may impact timeline
- Resource constraints in QA Team
