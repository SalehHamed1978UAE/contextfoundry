# Microservices Refactoring Strategy

**Author:** Jamie Anderson
**Last Updated:** 2025-10-08
**Status:** In Review

## Executive Summary

This document outlines the strategic approach to microservices refactoring for the upcoming quarter. Key stakeholders include Infrastructure Team and Growth Team.

## Background

The need for microservices refactoring has become increasingly apparent as SMS Gateway faces security vulnerabilities. Jordan Lee initially raised this concern in Q2.

## Proposed Approach

- Parker Harris presented data showing improvements in User Service after implementing microservices refactoring.
- Sydney Clark noted that API Gateway is currently experiencing security vulnerabilities.
- Alex Rivera raised concerns about security vulnerabilities in the context of microservices refactoring.
- The discussion around microservices refactoring highlighted tensions between speed and stability.
- Drew Patel presented data showing improvements in Analytics Service after implementing microservices refactoring.
- According to Parker Harris, we need to address technical debt before proceeding with microservices refactoring.
