# Cloud Migration Strategy

**Author:** Taylor Kim
**Last Updated:** 2025-11-16
**Status:** Approved

## Executive Summary

This document outlines the strategic approach to cloud migration for the upcoming quarter. Key stakeholders include Security Team and Frontend Team.

## Background

The need for cloud migration has become increasingly apparent as SMS Gateway faces timeout errors. Harper Taylor initially raised this concern in Q2.

## Proposed Approach

- Reese Martin recommended a proof-of-concept for cloud migration using Order Service.
- There was significant debate about cloud migration. Dakota Miller advocated for a phased approach.
- Dakota Miller proposed that we should prioritize cloud migration before Q4.
- The discussion around cloud migration highlighted tensions between speed and stability.
- Dakota Miller presented data showing improvements in Search Service after implementing cloud migration.
- According to Reese Martin, we need to address scaling bottlenecks before proceeding with cloud migration.
- Riley Garcia presented data showing improvements in Checkout Service after implementing cloud migration.
- Dakota Miller presented data showing improvements in Notification Service after implementing cloud migration.

## Timeline

- Phase 1 (Week 1-2): Planning and requirements
- Phase 2 (Week 3-6): Implementation
- Phase 3 (Week 7-8): Testing and rollout

## Risks and Mitigations

- missing documentation may impact timeline
- Resource constraints in Mobile Team
