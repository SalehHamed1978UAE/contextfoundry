## Threat Summary

| Element | Detail |
|---------|--------|
| Threat Type | Credential Harvesting Phishing |
| Target | All Nexus employees |
| Vector | Email with link to fake login page |
| Sophistication | HIGH |
| Status | Active campaign |

## What Happened

On December 11, 2025, a sophisticated phishing campaign targeted Nexus employees. The attack was detected and contained on December 12 before any significant damage occurred. However, all employees must be aware of this ongoing threat.

## Attack Characteristics

The phishing emails have the following characteristics:

| Element | Description |
|---------|-------------|
| Sender | Appears to be from "IT Department" or "Nexus IT Support" |
| Subject | "Urgent: Password Update Required" or similar |
| Content | Claims password is expiring, requests immediate action |
| Link | Leads to fake Nexus login page |
| Domain | Uses look-alike domains (nexus-industries.co, nexus-it.com) |

## Example Email

```
From: IT Security <security@nexus-industries.co>  ← FAKE DOMAIN
Subject: Urgent: Your Password Expires in 24 Hours

Dear Employee,

Your Nexus Industries password will expire in 24 hours.
Click here to update your password immediately.

[Update Password Now]  ← DO NOT CLICK

Failure to update will result in account lockout.

IT Security Team
Nexus Industries
```

## How to Identify Phishing

**Red Flags:**

| Warning Sign | Example |
|--------------|---------|
| Urgency | "Immediate action required" |
| Threats | "Account will be locked" |
| Wrong domain | .co instead of .com |
| Generic greeting | "Dear Employee" vs. your name |
| Suspicious links | Hover to reveal actual URL |
| Grammar errors | Unusual phrasing |

**Remember:**
- Nexus IT will NEVER ask for your password via email
- We will NEVER threaten account lockout via email
- All legitimate password changes go through Okta portal

## What You Should Do

### If You Received a Suspicious Email

1. **DO NOT** click any links
2. **DO NOT** enter any credentials
3. **Report** the email using the "Report Phishing" button in Outlook
4. **Delete** the email

### If You Clicked a Link

1. **STOP** - do not enter any information
2. **Report** immediately to security@nexus-industries.com
3. **Change** your password at okta.nexus-industries.com
4. **Monitor** your account for unusual activity

### If You Entered Credentials

1. **Report immediately** to security@nexus-industries.com or call (602) 555-SAFE
2. **Change** your password from a known-safe device
3. **Enable** additional MFA if not already active
4. Your account may be temporarily suspended for protection
