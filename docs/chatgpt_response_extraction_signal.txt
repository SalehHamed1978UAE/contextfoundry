3. IMPLEMENTATION PREFERENCES
------------------------------

Given <1 week constraint, prefer:

LIGHTWEIGHT RULE-BASED ✅ (Priority 1)
- Pros: Fast to implement, interpretable, no training needed
- Cons: May not generalize beyond known patterns
- Examples: Regex patterns, heuristic scoring, graph analysis

LLM-BASED REASONING ✅ (Priority 2)
- Pros: Flexible, can handle edge cases, uses existing GPT-4o-mini
- Cons: Latency, API cost
- Examples: LLM judges extraction quality, LLM re-extracts on-demand

LIGHTWEIGHT ML ⚠️ (Priority 3 - only if quick)
- Pros: Can learn patterns from data
- Cons: Need training pipeline, evaluation harness
- Examples: Small classifier (sklearn), embedding-based similarity

DEEP LEARNING ❌ (Avoid for <1 week)
- Finetuning models requires: data prep, training, eval, deployment
- We don't have enough labeled data (only 100 questions)
- Timeline: 2-4 weeks minimum
- Save for long-term improvement
