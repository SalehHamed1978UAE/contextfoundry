### 2. HALLUCINATED Rate Analysis

The apparent increase in HALLUCINATED responses requires context:

**Evaluation Criteria:**
- HALLUCINATED = more unverified claims than verified claims
- The evaluator checks if **specific relationships** exist in the database

**What Changed:**
- Before: Many queries returned "entity not found" (classified as NOT_FOUND)
- After: Queries now find entities and make claims about relationships
- Those relationship claims may not all be in the database yet

**This is expected behavior** - the reasoning agent is making plausible inferences about entities that exist. The "HALLUCINATED" classification means the **relationships were not extracted** from documents, not that the agent fabricated entities.
